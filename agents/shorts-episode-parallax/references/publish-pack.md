# Publish pack: title, description, hashtags

Produce this after the episode file, or whenever the user asks for a title, description or hashtags. **Write it in the language of the video (Indonesian by default).** Explain to the user in the language they write in.

## What to deliver

1. **Titles:** 3 strong options plus 3-4 alternatives, and one recommendation with a one-line reason.
2. **YouTube Shorts description**, ready to paste.
3. **TikTok caption**, ready to paste.
4. **Hashtag pool**, grouped so the user can adjust per episode.
5. **Pinned comment** (optional): the main source and one closing question.
6. **Short usage tips** (see "Platform notes").

Every claim in a title or description must be as accurate as the video, with the same wording level (ESTABLISHED, DEBATED, LEGEND) as the episode's accuracy note. No clickbait that the video does not pay off.

## Titles

Titles should read like the question a person would type into a search box. Rotate between these formulas and use the one that matches the episode's twist:

- **The plain question:** "Kenapa Flamingo Berwarna Pink?" (the most searchable; use for common questions)
- **The surprising fact:** "Semua Flamingo Lahir Abu-abu"
- **The reframe (the twist line):** "Flamingo Tidak Lahir Pink. Mereka Diberi Makan Pink."
- **The hidden reason:** "Alasan Sebenarnya Flamingo Jadi Pink"
- **The what-if:** "Bagaimana Kalau Bumi Punya Cincin Seperti Saturnus?"
- **The mystery or origin:** "Siapa yang Pertama Menciptakan Nama Indonesia?"
- Series tag at the end when it fits: " | Mystery Lab #<NN>"

Guidelines:
- About 40-60 characters so the title is not cut off.
- The most searchable words first (the topic), the series tag last.
- For debated topics, never promise an answer the video does not give: use "Teori", "Apa yang Sebenarnya Terjadi", or the question form.
- Prefer the plain question or the surprising fact when the topic is a common search; on TikTok the first sentence of the caption is the title, so make it the hook.
- Do not reuse the same title frame in two consecutive episodes.

## YouTube Shorts description

Structure:

```text
<Hook question from the video>

<2-3 sentence answer in plain language, ending with the twist line>

<One detail that is NOT in the video: a counterpoint, a "where it gets interesting" fact>

Sumber: <1-3 institutional sources, names only>

<Series name> #<NN>: satu pertanyaan, dijawab dalam kurang dari 50 detik.

<If parts are simplified:> Catatan: karakter dan diagram dalam video ini adalah ilustrasi yang disederhanakan.

Ikuti untuk #<NN+1>.

<up to 15 hashtags>
```

- The "extra detail" and the source line are on purpose: they give the description original content and make it checkable, which supports the originality of the episode.
- **Vary the sentence frames** between episodes. Descriptions that repeat the same frame every time look like a template.
- Keep the wording level of the accuracy note: a debated topic says "ada yang berpendapat", not "ternyata".

## TikTok caption

Hook question with one emoji, 1-2 sentences of answer, one extra detail, the series line ("<Series> #<NN> · Ikuti untuk #<NN+1>"), then 5-10 lowercase hashtags including `#fyp` and a learning tag. Shorter than the YouTube description.

## Pinned comment (optional)

The main source, plus one question that invites a short answer ("Menurut kamu, teori mana yang paling masuk akal?"). For debated topics this also reminds viewers that the topic is open.

## Hashtag pool

- **Series core (always):** `#MysteryLab` and the series hashtag if the episode belongs to one (for example the regional series).
- **Topic:** terms about this episode's subject (for example `#Flamingo`, `#Alam`, `#SejarahIndonesia`, `#Astronomi`).
- **Education and curiosity:** `#FaktaUnik`, `#TahukahKamu`, `#Edukasi`, `#BelajarDiTikTok`, `#LearnOnShorts`, `#Sains`, `#Sejarah`
- **Style:** `#Animasi`, `#VideoEdukasi`, `#Explained`
- **Platform:** `#Shorts`, `#YouTubeShorts`, `#fyp`, `#fypindonesia`

Hashtags are search categories, not on-screen mentions. A topic hashtag that names a well-known product is acceptable when it is genuinely what viewers search for; use it sparingly.

## Platform notes

These reflect how the platforms behaved when this skill was written and can change; tell the user to confirm in the app when it matters.

- **YouTube:** the first three hashtags of the description are shown above the title, so put the most important ones first (series tag, topic, topic). Stay at 15 hashtags or fewer.
- **TikTok:** 5-10 focused hashtags are usually enough: one broad, a few specific, one series tag.
- **Consistency:** reuse the same series and channel hashtags on every episode so viewers can browse the whole series.
- **Playlists:** put each series in its own playlist so its performance can be read on its own.
- **Disclosure:** YouTube asks creators to disclose realistic altered or synthetic content that viewers could mistake for real, and exempts clearly unrealistic content such as animation. The narration is synthetic. If the voice imitates a real person, disclose it. Tell the user to read the disclosure question on the upload screen and follow the current rules; when unsure, answering yes is the cautious choice.
- **Clean exports:** upload the clean Remotion export to each platform directly, not a download from the other platform with a watermark.
- **Username vs display name:** display names can match across platforms, but the @username must be unique per platform; suggest close variants if the exact one is taken.

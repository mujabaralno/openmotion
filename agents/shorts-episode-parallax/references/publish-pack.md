# Publish pack: title, description, hashtags (Everyday Why)

Produce this after the episode file, or whenever the user asks for a title, description, or hashtags. Write it in English (the video is in English) and keep the explanation to the user in the language they write in.

## What to deliver

1. **Titles:** 3 strong options plus 3-4 alternatives, and one recommendation with a one-line reason.
2. **YouTube Shorts description:** ready to paste.
3. **TikTok caption:** ready to paste.
4. **Hashtag pool:** grouped, so the user can adjust per episode.
5. **Short usage tips** (see "Platform notes").

Keep every claim in titles and descriptions as accurate as the video itself. No clickbait that the video does not pay off.

## Titles

This series answers everyday questions, so titles should read like the question a person would type into a search box. Formulas that fit (use the one that matches the episode's twist, and rotate between them across episodes):

- **The plain question:** "Why Are Flamingos Pink?" (the most searchable; use when the question is common)
- **The surprising fact:** "Every Flamingo Is Born Gray"
- **The reframe (the twist line):** "Flamingos Aren't Born Pink. They're Fed Pink."
- **The hidden reason:** "The Real Reason Flamingos Turn Pink"
- **Series tag at the end** when it fits: " | Everyday Why #01"

Guidelines:
- Aim for about 40-60 characters so the title is not cut off.
- The most searchable words come first (the topic), the series tag last.
- Recommend the one that is both clear and accurate. When the topic is a common search question, prefer the plain question or the surprising fact so the video can be found by search as well as by the Shorts feed.
- On TikTok the first sentence of the caption plays the role of the title, so make it the hook.

## YouTube Shorts description

Structure:

```text
<Hook question from the video>

<2-3 sentence plain-language answer, ending with the twist line>

<One extra detail not in the video (a counterpoint or a "where it gets interesting" fact), if the episode has one>

<Series name> #<NN> — one everyday question, answered in under 50 seconds.

<Accuracy note if parts are simplified: "Note: the character and the diagrams in this video are simplified illustrations.">

🔔 Follow for #<NN+1>.

<up to 15 hashtags>
```

The "extra detail" line is useful on purpose: it gives the description original content, which supports the originality of the episode. Use the facts from the accuracy note (for example, that zoo flamingos are given carotenoid-rich food to keep their color).

## TikTok caption

Structure: hook question with one emoji, 1-2 sentences of answer, one extra detail, series line ("<Series> #<NN> · Follow for #<NN+1>"), then 8-15 lowercase hashtags including `#fyp` and a learning tag. Shorter than the YouTube description.

## Hashtag pool

Group the pool so the user can mix and match:

- **Series core (always):** the series hashtag (for example `#EverydayWhy`) and the channel hashtag the user already uses on the other series.
- **Topic:** terms about this episode's subject (for example `#Flamingo`, `#Birds`, `#Nature`, `#Animals`, `#WildlifeFacts`).
- **Education and curiosity:** `#LearnOnShorts`, `#LearnOnTikTok`, `#DidYouKnow`, `#ScienceFacts`, `#FunFacts`, `#Explained`, `#WhyDoes`
- **Style:** `#Animation`, `#2DAnimation`, `#ExplainerVideo`
- **Platform:** `#Shorts`, `#YouTubeShorts`, `#fyp`

Hashtags are search categories, not on-screen mentions, so a topic hashtag that names a well-known product is acceptable when it is genuinely what viewers search for. Use it sparingly and only when relevant to the episode.

## Platform notes

These reflect how the platforms behaved when this skill was written. They can change, so tell the user to confirm in the app when it matters.

- **YouTube:** the first three hashtags in the description are shown above the title, so put the most important ones first (series tag, topic, topic). Staying at 15 hashtags or fewer is safest.
- **TikTok:** 5-10 focused hashtags is usually enough: one broad, a few specific, one series tag.
- **Consistency:** reuse the same series and channel hashtags on every episode so viewers can browse the whole series.
- **Separate playlist:** keep this series in its own playlist so viewers of the dark Mystery series are not shown a very different look by surprise, and so its performance can be read on its own.
- **Disclosure:** YouTube asks creators to disclose realistic altered or synthetic content that viewers could mistake for real, and exempts clearly unrealistic content such as animation. Because the narration is synthetic, tell the user to check the disclosure question on the upload screen and to follow the current rules there; if unsure, answering yes is the cautious choice.
- **Clean exports:** upload the clean Remotion export to each platform directly, not a download from the other platform with a watermark.
- **Username vs display name:** display names can match across platforms; the @username must be unique per platform, so suggest close variants if the exact one is taken.
